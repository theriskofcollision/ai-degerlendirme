# AI Otomasyon Değerlendirmesi / AI Automation Assessment

A single-page, bilingual (Turkish and English) questionnaire that helps a small business find the first task worth handing to AI. You list the work you repeat, the bottlenecks you hit, and the jobs that need the most checking. Then you score each task on how much AI could take on, opportunity cost, error rate, scalability and how well the process is documented. The result is a report that sorts tasks into automate, AI-with-human-review, or keep human. It follows the "should AI do it, not can AI do it" approach.

It is everything in one file, `index.html`, with no build step and no server. Open it in a browser.
